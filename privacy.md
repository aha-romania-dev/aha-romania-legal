# Privacy Policy for Aha! Romania Publisher

**Effective date:** 19 May 2026
**Last updated:** 19 May 2026

## 1. Introduction

This Privacy Policy describes how "Aha! Romania Publisher" (hereinafter "the Application", "we", "us") handles information when you use our content publishing tool.

The Application is a personal automation tool developed by an individual content creator to facilitate publishing of educational content to the TikTok account "@aharomania" via TikTok's Content Posting API.

## 2. Information We Process

The Application is designed for single-user personal use by its owner. We do not collect, store, or process information from any third party or external user.

When operated, the Application processes:
- TikTok API authentication tokens for the owner's TikTok account
- Video files, captions, and metadata uploaded by the owner
- Publishing status responses from TikTok's API

All data is stored locally on the owner's personal computer and is not transmitted to any third party other than TikTok itself.

## 3. How We Use Information

Information is used solely for the purpose of:
- Authenticating with TikTok's Content Posting API
- Uploading video content to the owner's TikTok inbox
- Tracking publishing status and analytics from the owner's content

We do not sell, share, or distribute any information to third parties.

## 4. Data Storage and Security

All application data is stored locally on the owner's personal device. API credentials are stored using industry-standard encryption practices. No data is transmitted to external servers other than TikTok's official API endpoints.

## 5. Third-Party Services

The Application interacts exclusively with TikTok's official API. TikTok's own privacy policy governs how TikTok processes data received through the API: https://www.tiktok.com/legal/privacy-policy

## 6. User Rights

As the Application is for personal single-user operation by the owner, standard GDPR data subject rights apply only to the owner themselves, who has full control over all data processed by the Application.

The owner may at any time:
- Delete all locally stored data
- Revoke TikTok API access tokens
- Discontinue use of the Application

## 7. Children's Privacy

The Application is not intended for use by individuals under the age of 18 and does not knowingly collect any data from minors.

## 8. Changes to This Policy

We may update this Privacy Policy from time to time. The most current version will be available at the URL where you accessed this document.
